# 葡萄小农场 · 动态特效

这套独立动态预览沿用新农场像素方案，包含可交互的动画播放器与无声视频。展示花期被压缩到 16 秒，不代表真实 DDL 时间，也不提交分类请求。

## 观看

- `farm-garden-motion-closeup.mp4`：近景，1152×384，16 秒，24fps，无音轨。
- `farm-garden-motion.mp4`：完整舞台，1152×576，16 秒，24fps，无音轨。
- `index.html`：可暂停、切换六阶段、模拟投喂、触发阵风及切换深浅背景。

从本目录运行本地预览服务，再打开浏览器：

```bash
python3 -m http.server 18777 --bind 127.0.0.1
```

访问 `http://127.0.0.1:18777/index.html`。静态服务与 8765 端口的分类核心独立。

## 动作安排

| 时间 | 花期和特效 |
| --- | --- |
| 0–2 秒 | 含苞，藤叶保持轻微、分相位的风摆 |
| 2–4 秒 | 待放；2.4 秒模拟投喂，紫葡萄由悬挂点受力回弹并给出短促像素反馈 |
| 4–6 秒 | 初绽，保持花梗根部支点 |
| 6–10 秒 | 盛放；6.2 秒一阵风依次传递到叶片与卷须 |
| 10–13 秒 | 萎垂，花头向左低下，花瓣保留橙色 |
| 13–16 秒 | 凋零；一片花瓣独立脱落，向下飘过木架，残花保留 |

播放结束后只继续环境微动，不自动回到花苞。点击“重播花期”才重新开始。减少动态设置下保留静态状态和手动查看。

## 素材与实现

- `plant-sprites.png`、`flower-states.png`：imagegen 生成的分层像素部件与完整花期关键姿态。
- `assets.json`：部件范围、统一的显示比例及悬挂/花梗支点。
- `scene.js`：独立运动计算，葡萄、叶片、花朵共享同一条藤蔓的支点。
- `tools/`：用同一套动作计算逐帧合成并导出视频的工具。
- `contact-sheet.png`、`keyframes/`、`media-checks/`：关键帧及编码后的视频抽帧。
- `GENERATION.md`：内置 imagegen 的完整提示词。

制作方法为 AI 像素素材加本地逐帧合成。已检查六阶段轮廓、悬挂接触、木架固定、葡萄回弹和落瓣可读性，并验证视频时长、帧率与无音轨。像素部件在低分辨率画布内运动，再以最近邻放大。
