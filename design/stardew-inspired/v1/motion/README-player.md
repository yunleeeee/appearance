# 葡萄小农场 · 动态预览

`index.html` 是独立的动态试片界面。用静态文件服务打开此目录后，访问它即可；页面只读取同目录的素材与动画脚本，不调用分类核心，不写入真实 DDL 或文件计数。

交互：

- 模拟投喂：触发果串与枝条的短促回弹，不增加真实文件或葡萄计数。
- 一阵风：触发叶片与嫩藤的轻摆。
- 重播花期：从含苞重新演示至凋零。
- 花朵状态：固定查看六个阶段之一；选择“自动花期”恢复推进。
- 花期进度：拖动查看动画中的具体时刻。
- 浅色/深色：比较素材在两种桌面背景上的可读性。

16 秒花期只用于动作演示，凋零后保持残花，只有主动重播才重新含苞。遵循系统的“减少动态效果”；启用时初始暂停，仍可拖动花期查看状态。

## 素材接口

页面读取 `assets.json`，其 `images` 指定图片路径，`sprites` 指定运行时裁切与支点：

```json
{
  "images": {"plants": "plant-sprites.png", "flowers": "flower-states.png"},
  "sprites": {
    "grapePurple": {
      "image": "plants", "x": 0, "y": 0, "w": 100, "h": 140,
      "nativeW": 25, "nativeH": 35, "anchorX": 12, "anchorY": 0
    }
  }
}
```

以上数字仅示意字段，不是实际裁切值。`scene.js` 提供 `FarmMotion.scene(t, options)` 的可复用绘制指令，其完整舞台为 384×192 逻辑像素，完整视频也保留这个比例。交互页面只显示舞台 y=48…176 的 384×128 区域，收紧上下留白；原始指令坐标不变，再以清晰像素方式显示。

供预览检查使用的只读状态接口为 `window.motionPreview.getState()`；`renderAt(t, options)` 会暂停并渲染指定时间，便于核对关键动作。它们不连接外部服务。
