# 花与葡萄藤 · 最终组合预览

花朵 v2.0 已封存于 `../../releases/flower-v2.0-2026-10-30/`，并保存为同名 ZIP，包含源素材、动作计算、交互页、导出器、成片与 SHA256 校验清单。

本组合稿引用封存的花朵形象和动作，加入像素藤蔓、木架、叶片和三色葡萄。花在上方，葡萄悬在下方。

## 显示状态

- 完整组合：花朵、连接茎、藤蔓、木架和葡萄同时显示。
- 仅花朵常驻：保留花头与花萼旁的短花梗，长连接茎、侧叶和花园层隐藏。
- 演示淡出：0–4 秒完整组合，4–6 秒花园层淡出，6–12 秒只有花朵常驻。花头没有重置、移动或跟随淡出。

根据后续反馈，常驻部分的花梗缩短为最多 5 个原生像素，去掉了下方长“根”的观感；完整组合中长茎仍作为与藤蔓连接的部分显示。这是组合展示层调整，封存包保持原样。
