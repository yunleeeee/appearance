## 资源接口

先加载 `flower-engine.js`，再加载 `scene.js`。组合引擎提供 `window.CombinedMotion.scene(time, options)`，播放器传入 `visibility: 'all' | 'flowers' | 'transition'`、`transitionAt: 4`、`fadeDuration: 2`，以及相同的花朵、风力参数。

`assets.json` 定义各个图片和部件。精灵的 `x/y` 是支点；`clipPolygon` 为支点局部坐标，旋转和缩放后先裁切再绘制。显示区域为完整舞台的 y=48…192，保持分数像素运动和像素图的最近邻取样。

调试状态可通过只读的 `window.combinedPreview.getState()` 查看，包括载入状态、展示模式、背景、花园层透明度和缺失部件。

从本目录启动静态服务并访问：

```bash
python3 -m http.server 18779 --bind 127.0.0.1
```
