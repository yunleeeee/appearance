按用户桌面截图中右下角的手绘布局，新建独立构图设计。此处为静态设计图，尚未接入桌面动画。

- [完整组合](desktop-all.png)：右侧木架承载葡萄、葡萄叶、藤和卷须；花朵独立长在底边草丛中。
- [仅花常驻](desktop-flowers-only.png)：隐藏木架和葡萄层，保留底边的花与草。
- 花型沿用已批准的莓玫瑰方向：奶油色瓣缘、莓红层叠花瓣、深梅色褶皱、金色花心。
- 小草遮住短茎基部，没有露根或悬浮花头。中央桌面保持大面积留白。
- 两张为生成式构图参考，第二张以第一张为编辑目标；工程实现时应复用同一花丛图层，以确保切换像素一致。

生成方式：内置 `image_gen`，第一张参考截图、已批准花型和旧葡萄架；第二张移除葡萄架，保留花丛。
