# 常驻花朵 · 第二版

根据“上一版太僵硬、花朵需要单独常驻桌面”的反馈，重做花型并拆分动作。预览只保留花朵、短花梗和一片小叶，默认保持盛放，不自动演示至凋零。

## 观看

- `flower-presence.mp4`：常驻动效片段，6 秒，1152×384，24fps，无音轨。来自花期 6–12 秒的盛放时段，不宣称无缝循环。
- `flower-motion.mp4`：完整六阶段演示，20 秒，1152×384，24fps，无音轨。
- `index.html`：可触发阵风、切换花期、暂停，含深浅背景下的 1× 常驻大小预览。

本目录启动静态服务后访问 `http://127.0.0.1:18778/index.html`：

```bash
python3 -m http.server 18778 --bind 127.0.0.1
```

## 本版变化

花型为三分之四朝向的半重瓣小蔷薇，奶油色边缘、莓玫瑰色花腹、深梅色折瓣和少量暖金花蕊；以花瓣前后层叠代替正面放射圆盘。

动作以固定根部为起点，茎关节先受风，花头延后 90–140 毫秒，三组外瓣再依次跟随；风过后反摆一次并收势。风力有安静段，避免等幅来回摆动。花蕊跟随花头，不单独漂移；花梗连接实际花萼。

闭苞、待放、初绽、盛放、萎垂和凋零仍采用六个完整姿态。演示时间为 0、1.5、3、5、12、16 秒进入对应状态；它们是压缩的视觉演示，不是真实 DDL。逾期残花一直保留，只有重播才重新含苞。

## 文件与检查

- `assets.json` / `flower-atlas.png`：部件、尺寸、花心与花萼连接点。
- `scene.js`：固定根部、茎曲线、延迟跟随、花瓣分区和单片落瓣。
- `native-proofs/`、`native-proofs-dark/`：384×100 原生尺寸检查。
- `closeups/`、`closeups-dark/`：放大及阵风峰值检查。
- `media-checks/`：从最终 MP4 重新解码的检查帧。
- `tools/`：相同动作脚本的离线视频导出器。
- `GENERATION.md`：内置 imagegen 使用的完整提示词。

制作方法为 imagegen 关键素材加本地分层逐帧合成。已检查浅深背景、常驻大小、花梗连接、花瓣分层接缝与实际视频的落瓣可读性，并验证时长、帧率和无音轨。静态花期图之间仍是关键姿态切换；常驻风摆在分层部件上连续计算。
