# 常驻花朵 · 动态预览 v2

本页面聚焦三朵独立花的常驻表现，不展示木架、葡萄或其他农场组件。默认固定盛放，只播放轻风；不会自动从盛放走到凋零。用静态文件服务打开本目录后访问 `index.html`，页面只读取本目录的素材、清单与动画脚本，不调用真实分类或 DDL 服务。

## 交互

- **迎一阵风**：花梗、叶片与花头分别产生带相位差的摆动。
- **演示花期**：主动从含苞演示到凋零，全程 20 秒，之后保留残花。
- **暂停 / 播放**：停留查看动作或恢复播放。
- **花朵状态**：固定查看六种状态之一，同时保留轻风。
- **花期进度**：拖动进入花期演示的具体时刻。
- **浅色 / 深色**：切换放大预览的背景。

下方两条“常驻大小”预览始终并列显示浅色和深色背景，在宽屏上以 1× 原生逻辑像素展示，便于判断桌面占用。窄屏下会自适应缩小，避免横向溢出。

遵循系统的“减少动态效果”；启用时初始暂停，仍可手动拖动花期或选择阶段。演示时序不代表真实 DDL。

## 渲染接口

页面读取 `assets.json`，使用与 v1 一致的 `images` / `sprites` 清单，包含源图裁切、逻辑尺寸与支点。`scene.js` 提供 `FarmMotion.scene(t, options)`，默认传入 `mode: "standalone"`、`flowerStage: 3`、`gustAt: null`。主动演示后清除固定阶段，重新从 t=0 推进。

完整动作坐标仍为 384×192。放大预览显示全局 y=48…176 的 384×128 区域；常驻大小显示 y=60…160 的 384×100 区域，给花冠与随风动作留出完整空间。所有绘制指令保持原始坐标。播放器以 24fps 更新，以保留花头、花瓣与花梗之间的延迟跟随。

精灵可附 `clipPolygon`：在支点平移、旋转、缩放之后、绘图之前应用的局部坐标多边形，让花头与花梗能分开运动。页面保留最近邻采样，不对整朵花做模糊变形。

`window.motionPreview.renderAt(t, options)` 可暂停并渲染指定关键帧，`getState()` 返回已加载状态、花期、指令数量和缺失素材 ID，供预览核对。
