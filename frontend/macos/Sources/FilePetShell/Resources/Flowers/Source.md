# DDL 花朵素材

`Lifecycle.png` 沿用 `design/deadline-flowers/v1/flower-states-transparent.png`，为内置 imagegen 生成的六阶段概念素材，保留真实 Alpha。

`Compact.png` 是 `design/compact-garden/v1/flowers-source.png` 的逐字节副本。原生界面按原设计中的三株植物区域裁切，分别承载最多三个真实 DDL；其余 DDL 按顺序排队。悬停展示主要内容、时间和项目，点击收获后完成 DDL。花朵独立于葡萄藤的自动淡出，服从整个挂件的显示/隐藏开关；透明区域保持鼠标穿透。
